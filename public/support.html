Support

Beta support template. Last updated June 25, 2026.

Cancer Prevention Passport is currently preparing for controlled beta use. Public feedback can be filed through GitHub issues after removing personal or health information. Add a monitored production support email before public release.

Account and Data Requests

Signed-in users can export a local JSON copy of app data and delete app data/account records from the Profile tab.

Security or Privacy Concerns

Do not post protected health information, sensitive personal details, private tokens, or security concerns in public GitHub issues. Use GitHub Security Advisories for private security, privacy, or health-data concerns during beta.

Public Beta Feedback

Use the repository's bug report or beta feedback templates only for non-sensitive product, technical, UX, or clinical-language feedback.

Medical Questions

This app does not provide medical advice. Contact a licensed clinician for screening, symptoms, diagnosis, treatment, or survivorship care questions.
