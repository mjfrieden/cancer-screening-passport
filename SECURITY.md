# Security and Privacy Reporting

Last updated: 2026-06-25

Cancer Prevention Passport is preparing for controlled beta use. Do not include protected health information, real medical records, private tokens, or sensitive personal details in public GitHub issues, pull requests, screenshots, logs, or discussions.

## Private Reports

Use GitHub Security Advisories for private security, privacy, or health-data concerns:

```text
https://github.com/mjfrieden/cancer-screening-passport/security/advisories/new
```

Use a private report for:

- suspected cross-user data access,
- authentication or authorization weaknesses,
- Firestore rules bypasses,
- exposed secrets or tokens,
- accidental handling of protected health information,
- privacy, deletion, retention, or export failures that include sensitive details.

## Public Issues

Public GitHub issues are appropriate only for non-sensitive:

- app bugs,
- product feedback,
- accessibility issues,
- layout problems,
- documentation issues,
- cautious clinical-language feedback that does not include a real person's health details.

Before filing a public issue, remove names, dates of birth, locations, medical record numbers, account identifiers, screenshots containing personal data, and any other information that could identify a person.

## Current Beta Boundary

The beta should be treated as a non-PHI testing environment until production privacy, compliance, support, retention, access control, audit, and vendor-review processes are complete.
